# Forensic Workflow

1. Work from a copy of the evidence when practical.
2. Record the SHA-256 fingerprint before analysis.
3. Analyze without trusting the filename extension.
4. Record magic bytes, size, entropy, strings, and partition evidence.
5. Prefer JSON reports for machine processing and text reports for humans.
6. Treat low-confidence results as hypotheses, not facts.
7. Never modify the original evidence with this tool.

Digital Archaeologist is an analysis utility, not a court-specific evidence-management system. Maintain your own chain-of-custody procedures where required.
